Thesaurus Help
Thesaurus is software for detecting positional phosphopeptide isomers from DIA data.
You should prefix your arguments with a high memory setting, e.g. "-Xmx8g" for 8gb
Required Parameters:
	-i	input .DIA or .MZML file
	-f	protein .FASTA database
	-l	library .ELIB file
Other Parameters:
	-o	output report file (default: [input file].thesaurus.txt)
	-acquisition                         (default: DIA)
	-adjustInferredRTBoundaries          (default: false)
	-enzyme                              (default: trypsin)
	-expectedPeakWidth                   (default: 25)
	-filterPeaklists                     (default: false)
	-fixed                               (default: C=57.0214635)
	-foffset                             (default: 0)
	-frag                                (default: CID)
	-ftol                                (default: 10)
	-ftolunits                           (default: ppm)
	-integratePrecursors                 (default: false)
	-lftol                               (default: 10)
	-lftolunits                          (default: ppm)
	-localizationModification            (default: none)
	-maskBadIntegrations                 (default: false)
	-maxWindowWidth                      (default: -1)
	-minIntensity                        (default: -1.0)
	-minIntensityNumIons                 (default: -1.0)
	-minNumIntegratedRTPoints            (default: 3)
	-minNumOfQuantitativePeaks           (default: 3)
	-normalizeByTIC                      (default: true)
	-numberOfExtraDecoyLibrariesSearche  (default: 0.0)
	-numberOfQuantitativePeaks           (default: 5)
	-numberOfThreadsUsed                 (default: <host cores>)
	-peakPickTimsIMS                     (default: true)
	-percolatorProteinThreshold          (default: 0.01)
	-percolatorThreshold                 (default: 0.01)
	-percolatorTrainingFDR               (default: 0.0)
	-percolatorTrainingSetSize           (default: 500000)
	-percolatorVersion                   (default: v3-01)
	-poffset                             (default: 0)
	-precursorIsolationMargin            (default: 0)
	-precursorWindowSize                 (default: -1)
	-predictRawSettings                  (default: true)
	-ptol                                (default: 10)
	-ptolunits                           (default: ppm)
	-rtWindowInMin                       (default: -1.0)
	-scoringBreadthType                  (default: recal)
	-skipLibraryRetentionTime            (default: false)
	-smoothIntegrations                  (default: true)
	-subtractBackground                  (default: true)
	-topNTargetsUsed                     (default: 10)
	-usePercolator                       (default: true)
	-verifyModificationIons              (default: true)
	-quiet	suppress log output to stdout/stderr
